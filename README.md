# SmartCampus AI

Plateforme d'orientation universitaire intelligente pour l'IIT et l'ISB.

## Organisation Git

- `main` : versions stables
- `develop` : intégration des fonctionnalités
- `feature/SA-*` : branches liées aux stories Jira

Le projet est organisé en Backend, Frontend, base de données, contrats d'API et documentation.
